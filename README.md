# 📘 Grading Book
A simple, intuitive grading and progress‑tracking app in progress, designed for teachers, tutors, and parents who want a clean way to record student performance and monitor improvement over time.

## Overview
Grading Book is being built to help educators track daily tasks, assignments, and learning progress through a friendly, streamlined interface. The focus is on clarity, ease of use, and visual motivation — making it ideal for classrooms, homeschooling, or tutoring sessions.

Developed in FlutterFlow and powered by Firebase, the app will support real‑time updates, secure data storage, and smooth cross‑platform performance.

## Features
## Student Progress Tracking  
Record scores, tasks, and learning milestones with ease.

## Daily Streak System  
Encourage consistency and motivate students with visual streaks.

## Subject & Topic Modules  
Organize learning into categories like Basic Operations or Geometry.

## Clean, Modern UI  
Simple layouts and thoughtful design for quick navigation and minimal friction.

## Firebase Integration  
Authentication, Firestore database, and secure cloud storage.
